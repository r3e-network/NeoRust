NeoRust / neo-rust-sdk is a Rust 2021 workspace for the Neo N3 blockchain. The main crate is `neo3`; the repo also contains `neo-cli`, many examples, docs, and supporting modules. High-level architecture: `neo_builder` (scripts, transactions, signers, witnesses), `neo_clients` (JSON-RPC clients, transports, extensions, mock clients), `neo_crypto` (keys, hashes, WIF, NEP2), `neo_protocol` (accounts, RPC response models, protocol helpers), `neo_wallets` (runtime wallet APIs and NEP-6 models), `neo_types` (shared primitive/value types), plus `neo_contract`, `neo_fs`, `neo_x`, `sdk`, and `neo_error`. The crate root already exposes a broad Rust-native API; as of 2026-03-15 there is also a new Python-shaped compatibility facade under `src/neo/` with `neo`, `neo::rpcclient`, and `neo::wallet` modules.
