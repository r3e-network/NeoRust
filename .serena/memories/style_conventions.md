Code style in this repo follows `rustfmt.toml`: hard tabs, max width 100, reordered imports, Unix newlines, field init shorthand. The codebase prefers explicit types and rich documentation comments on public items. Many modules re-export submodules through top-level `mod.rs` files. Avoid destructive git cleanup because the worktree may be dirty. Use `apply_patch` for edits. Prefer adding thin compatibility layers over moving large internal modules unless the task explicitly requires a deep rewrite. Existing naming is mixed: Rust-native modules (`neo_builder`, `neo_clients`) plus compatibility aliases (`builder`, `providers`, etc.) in `src/lib.rs`.
